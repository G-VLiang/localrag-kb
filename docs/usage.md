# 使用指南（团队协作）

## 角色与权限

| 角色 | 读取 | 写文档/建库 | 管理成员 | 删空间 |
|---|---|---|---|---|
| owner（空间创建者） | ✅ | ✅ | ✅ | ✅ |
| admin | ✅ | ✅ | ✅ | ❌ |
| editor | ✅ | ✅ | ❌ | ❌ |
| reader | ✅ | ❌ | ❌ | ❌ |

> 角色是**空间级**的；空间内所有知识库对该空间成员可见。

## 组队流程

1. 首页点「+ 团队空间」，输入名称。
2. 进入空间，右上角「成员」→ 输入同事**邮箱**（对方需先注册）→ 选角色 → 邀请。
3. 成员即可在自己的「我的空间」列表里看到该团队空间。

## 知识沉淀

- **写文档**：文档树「+ 文档」→ 编辑器编辑 → 「保存」（保存会自动建向量索引）。
- **建文件夹**：文档树「+ 文件夹」，按方向/成员归档；节点悬停可 **重命名 / 移动 / 删除**。
- **导入**：文档树「导入」支持 PDF / Word(docx) / Markdown / TXT，导入后**自动建索引**。
- **版本历史**：每次保存生成快照（API `/kb/{id}/nodes/{id}/versions`）。
- **导出**：API `/kb/{id}/nodes/{id}/export`。

> **最佳实践**：文档用**标题层级**（H1/H2…）组织内容——切片会记录标题路径并拼入向量，显著提升检索命中与引用可读性（引用会显示「文档 › 章节」）。

## 智能问答（替补找方案的核心）

1. 左侧勾选要检索的知识库（可多选）。
2. 切到「智能问答」，输入问题回车。
3. 返回答案 + **来源引用**（文档 › 章节、相关度、片段摘要）；**点击引用可直接打开该文档**。

检索链路：向量召回 + 关键词召回 → RRF 融合 → 词法重排 → MMR 多样性 → 父块上下文扩展 → LLM 生成（带引用）。

若答案不准，可尝试：
- 确认相关文档已「保存/导入」并被索引（右上角显示片段数）。
- 用更具体的关键词提问。
- 在 `.env` 开启 `USE_QUERY_REWRITE=true`（需 LLM）做问题改写。

## 全文搜索

文档树上方搜索框输入关键词回车，列出匹配文档，点击打开。

## 分享

对单篇文档生成分享链接（可设密码/有效期，API `/nodes/{id}/share`、`/share/access`），适合把某份方案发给空间外的人。

## 审计

- 所有写操作（登录/注册/保存/建库/导入/索引/分享…）自动留痕。
- 「操作日志」页：普通用户看**自己的**；管理员（`ADMIN_EMAILS`）可切「全部」。
- 数据字段：动作、方法、路径、状态码、IP、时间。
